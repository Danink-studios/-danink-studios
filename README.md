# Danink Studios — GitHub Pages

This is the complete single-file website for Danink Studios.

## Upload
1. In the GitHub repository, open **Add file → Upload files**.
2. Upload `index.html` and `.nojekyll` from this folder.
3. Replace the old `index.html` when GitHub asks.
4. Commit the changes.
5. In **Settings → Pages**, make sure the site publishes from the `main` branch and the `/(root)` folder.

The website includes the Danink Studios branding, portfolio sections, contact details, phone number `0111479929`, email contact, and WhatsApp contact button.

## Important
Upload `index.html` as an HTML file. Do not paste its contents into `README.md` or a Markdown file.
